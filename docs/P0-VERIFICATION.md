## Reproduce locally

Use the isolated validation interpreter or install `requirements.txt` and `requirements-dev.txt` into a new Python 3.12 environment, then run:

```powershell
python -m pip check
python scripts/p0_lock_check.py
python scripts/p0_import_smoke.py
python -m pytest tests/security/test_p0.py -q
python scripts/p0_local_smoke.py
python scripts/p0_secret_scan.py
```

The real-process smoke check requires valid local security/OAuth configuration but does not exchange an authorization code or contact a provider. Test databases are temporary. Preserve the local token encryption key separately from production backups.
